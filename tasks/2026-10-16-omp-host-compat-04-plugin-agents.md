# Ship the ADR 0013 subagents in the plugin's `agents/` folder

## Routing and approvals

- tier: standard (S2 holds: same symlink pattern as the canonical skills root layout, ADR 0014; S1, S3–S8 hold)

## Objective

The ADR 0013 subagents `researcher` and `validator-guide` live in `.claude/agents/`. That is a project folder, which OMP skips on purpose ("their frontmatter schema is not the OMP task-agent contract", `omp://task-agent-discovery.md`), and the Claude plugin loader doesn't read it either. Both Claude Code and OMP load agents from `<plugin root>/agents/*.md` when the plugin is installed. A probe on 2026-10-16 confirmed that OMP's `task` tool lists such an agent. Move the two files to a root `agents/` folder, keep `.claude/agents` as a relative symlink to it so project-level Claude Code use is unchanged, and fix the tool names: `ReadFile` is valid in neither host.

In scope:

- `git mv .claude/agents/researcher.md agents/researcher.md` and `git mv .claude/agents/validator-guide.md agents/validator-guide.md`.
- Replace the `.claude/agents` directory with a symlink `.claude/agents -> ../agents`.
- In both files, change only the tool `ReadFile` to `Read` in the `tools` list. The body stays byte-identical.
- This task record.

Out of scope:

- Agent bodies, names, descriptions. No `model` key: OMP drops `model` from Claude-dialect plugin agents.
- `.omp/agents/` (rejected: a second copy outside the plugin would drift).
- `docs/architecture/macro-map.json` (generated by `gira index`; it is refreshed whenever gira runs next, not by hand).
- Skills, hooks, `manifest.json`, README (task 09).

## Acceptance criteria

- AC1: `agents/researcher.md` and `agents/validator-guide.md` exist, and `.claude/agents` is a symlink: `readlink .claude/agents` prints `../agents`.
- AC2: `git diff -M main -- agents/` shows two renames, and the only changed line in each is the `tools` list item `- ReadFile`, which becomes `- Read`.
- AC3: OMP discovers the agents from the plugin. Run the probe in Plan step 4 once: the answer names `researcher` and `validator-guide`. If the default-profile marketplace list already contains `g-inga` (B2), record `blocked` and stop, so the owner's setup is never removed.
- AC4: after the probe, `omp plugin marketplace list` (default profile) matches B2, and the temp directories are gone.
- AC5: `mise run validate` and `mise run test` pass.
