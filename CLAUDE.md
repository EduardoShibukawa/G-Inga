# G-Ingá

A personal SDLC harness for Claude Code that grows from real friction and favors **tokens per verified task**. Currently in **M0 (discovery and specification)**: write documentation and decisions only. Don't implement until a spec is approved.

- Talk with the owner in Brazilian Portuguese. Write repository docs in English.
- Start with [docs/decision-map.md](docs/decision-map.md). Principles are in [docs/principles.md](docs/principles.md) and decisions in [docs/decisions/](docs/decisions/).
- The briefs in [docs/briefs/](docs/briefs/) are background input, not approved requirements.
- Label decisions and claims as `proposed`, `accepted`, `open` or `superseded`. Only the owner accepts.
- Report checks as `pass`, `fail`, `blocked` or `not run`.
